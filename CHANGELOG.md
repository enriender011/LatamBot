- Mejorado comando /ping: ahora muestra la latencia del bot.
- Nuevo comando /userinfo: muestra la siguiente información:
    - Username
    - Foto de perfil
    - Nombre de visualización

- nuevo comando /serverinfo que muestra información relevante sobre el servidor:
    - Nombre
    - Propietario
    - Número de miembros
    - Icono
    - Fecha de creación
